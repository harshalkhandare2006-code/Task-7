
# Tutedude MERN Stack – Task 7

## About
A responsive laundry services landing page created using HTML and CSS.

## Features
- Responsive navigation bar
- Navbar links hidden on mobile screens
- Responsive hero section
- Flexbox layout
- Tablet and mobile responsive design
- Laundry service booking button

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or extract the project files.
2. Open `index.html` in your browser.
3. Resize the browser window to check responsiveness.

## Project Files
- `index.html` – HTML structure
- `style.css` – Styling and responsive design

## Note
This project uses CSS media queries and Flexbox. Bootstrap is not used.
